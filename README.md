# E-Learning

An e-learning website landing page built with React and Vite. It introduces the learning platform and gives users a simple starting point for exploring online courses.

## Clone the repository

```bash
git clone https://github.com/silkflows/e-learning.git
cd e-learning
```

## Getting started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
